# Crypto Analyzer

Aplicación para análisis de patrones criptográficos con detección de candlestick patterns, indicadores técnicos y análisis de noticias correlacionadas.

## Stack Tecnológico

**Backend:**
- Django + Django REST Framework
- PostgreSQL / SQLite
- CCXT (descarga de datos de exchanges)
- Pandas & NumPy (análisis técnico)

**Frontend:**
- React 19
- Vite
- Recharts & Lightweight Charts
- TailwindCSS

## Deployment

- **Backend:** Render
- **Frontend:** Vercel
